# 关于本站

本站的设计灵感来自 macOS [Big Sur](https://www.apple.com/in/macos/big-sur/) 和 [Catalina](https://www.apple.com/bw/macos/catalina/)，使用 [React](https://reactjs.org/)、[Zustand](https://zustand-demo.pmnd.rs/) 与 [UnoCSS](https://uno.antfu.me/) 开发，并托管在 [Github Pages](https://pages.github.com/)。部分图标使用 [sindresorhus/file-icon-cli](https://github.com/sindresorhus/file-icon-cli) 生成。

源代码托管在[这里](https://github.com/sissiyu123456789-prog/playground-macos)。
