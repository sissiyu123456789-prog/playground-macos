# 交易Agent · 意图体系落地

> 💡 **项目速览**：面向生服泛交易场景，以意图体系驱动 AI 搜索 Agent 形成种草—拔草闭环：渗透率 51.0%→83.7%，周人均使用 4.2→9.6 次，人均对话 1.8→3.5 轮。

## 1. 背景与目标

泛交易意图=带场景、经验、推荐诉求的搜索，量大但转化低、潜力巨大。

- **竞品短板**：意图理解不足、内容冗长、屏效不足、单向输出。
- **业务目标**：突出抖音种草交易闭环优势，提升种草到交易转化效率。
- **产品目标**：构建「意图驱动、高效决策、深度协同」的 Agent 范式。
- **范围目标**：以曝光×转化坐标聚焦 Top1——POI 推荐 pv43.2%、攻略 pv34.5%、问答 pv15.1%，四象限分别提转化、低优暂不做、扩曝光、做体验。

![曝光×转化四象限](/markdown/trading-agent-assets/fig2_scope.jpg)

## 2. 方法论与场景实践

- **意图体系**：由「精泛搜·强弱意图」细化为「内容类·交易类」，传统搜分类做召回标签，AI 搜分类做回答蓝图。
- **意图工程**：人机协同——人类侧按分级/定义/query/承接思路拆解，AI 侧抽样 2 万条真实 query 打标、单标签 JSON 输出。
- **承接框架**：找店/团购「简要总结+feeds」、找内容「完整总结+feeds」、找信息「内容回答+下挂 POI」。

![生服 query 意图体系细化升级](/markdown/trading-agent-assets/fig1_intent.jpg)

找店/团购按意图强弱走完「种草→拔草」：找推荐重内容、找店铺内容+交易外露团购、找团购强交易外展行动点；种草交易同屏，超链直达 7 分屏、吸顶外露决策点、一键触底追问。

![种草心智与交易效率同屏协作](/markdown/trading-agent-assets/fig3_trade.jpg)

找内容（攻略）分层响应：泛搜分视觉叙事、文本叙事两种逻辑；精搜「泛搜给方向、精搜给路径」，全局可调序、局部可替换。

![攻略泛搜两种逻辑](/markdown/trading-agent-assets/fig4_guide.jpg)

找信息聚焦高流量场景做「可视化·真人实感」：常规问答下挂 POI，对比类升级决策卡片，热点类聚合价格、探店与团购。体验设计上，Thinking 用推理可视化让思考看得见（展示「找到 18 篇参考内容、35 家人气餐厅」等真实动作），追问用三层提问矩阵（回答收敛、单体下钻、按距离/预算/风格/设施引导选择）承接深挖。

## 3. 数据验证与最终价值

- **全域触点扫描**：站外（push、长按）与站内（TAB、播放器、内流）盘点，视频流兴趣激发、搜后延展消费等方案。
- **数据不是答案，而是追问的开始**：渗透率靠触点盘点提升，频次靠 feed 召回，轮次区分「被迫多轮」与「任务多轮」，以准确率、主动追问、任务暂停应对。

实现从「匹配 Query」到「理解 Need」：由扩写 query、关键词召回升级为意图拆解并行、语义向量混合召回、LLM 语义重排与事实校验，从「人找信息」到「信息找人」。

![从匹配 Query 到理解 Need](/markdown/trading-agent-assets/fig5_logic.jpg)

- **全局俯瞰**：沿「激发→种草→决策→下单」梳理产品框架与二跳承接，统一体验与交易指标。
- **见微知著**：POI 卡按「识别→判断→下单」归类信息，三级梯度沉淀标签规范。
- **最终价值**：沉淀意图体系、工程闭环、场景范式、体验设计、POI 卡规范五类可复用资产。
